## The line

> The agenda had one item — the email — and we spent the meeting deciding whether to discuss it.

94 characters, one line, one sentence: the meeting's only agenda item is the email itself, and the whole meeting is spent deciding whether to even discuss it — the recursion is the joke, and it lands on the last word.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
